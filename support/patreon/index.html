    Support on Patreon

    Gero is developed by a solo developer in spare time. Your support on Patreon makes continued development possible.

    Why Patreon?

    Your support helps cover:

    • Development time — New features, bug fixes, and improvements
    • Infrastructure — Build pipelines, testing, and hosting
    • Documentation — Guides and tutorials
    • Design — UI/UX improvements

    What you get

    As a Patreon subscriber, you get access to:

    • The supporter downloads page — Log in with Patreon at gero-downloads.geroappdev.workers.dev for everything your tier unlocks
    • Latest builds — The Windows app, Android app and browser extensions, older versions included
    • Gameplay recordings — Watch how the arcade games play out, searchable by game
    • Updates — New features and bug fixes as they're released, plus an update key so Gero can fetch releases for you
    • Community voting — Help decide which features get built next
    • Direct support — Priority bug reports and questions

    Subscribe on Patreon

    How it works

    1. Subscribe — Pick a tier on Patreon
    2. Download — Log in with Patreon at the supporter downloads page and grab the latest build
    3. Install — Follow the Installation guide
    4. Enjoy — The app is yours forever

    Lifetime use

    Once installed, Gero works forever — even without an active subscription. You only need a subscription to download new updates with the latest features and fixes.
